# Crypto Web Miner

A web-based cryptocurrency miner built with JavaScript.

## Features

- Mine cryptocurrency directly from your browser
- Easy to use interface
- Real-time statistics
- Support for multiple mining pools

## Installation

1. Clone the repository
2. Open `index.html` in your web browser
3. Start mining
